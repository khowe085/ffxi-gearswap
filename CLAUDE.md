# Notes for Claude

- Read `docs/ffxi-mechanics.md` before building or changing gear sets. It covers the caps, formulas and placement rules sets are built around (casting time, recast, haste, accuracy and attack, magic accuracy, enhancing, enfeebling, magic damage, Cure, blue magic, weapon skills). The player's standing rules for Vanar's sets are in `data/Vanar/Vanar_notes.md`, with Vanar's merits, job points and Master Levels.
- Check `docs/gear-notes.md` for any piece you put in a set. It records what the help text and the export don't show: hidden values, set bonuses, conditions and slot or hand restrictions. `data/Vanar/Vanar_gear_notes.md` adds what is known of Vanar's own copy.
- For path-augmented gear (Nyame, Bunzi's, Gleti's and other "Path:" items), take values from `docs/rank-augments.md` at Vanar's rank, which `data/Vanar/Vanar_rank_augments.md` gives. `//gs export` shows the path but not the rank.
- `docs/` holds what is true for any character and names none. What is true for one character goes in that character's folder under `data/`, linked from its `<Character>_gear_list.md`.
- Building, changing or reviewing gear sets is the `gear-optimizer` agent's job (`.claude/agents/gear-optimizer.md`). It takes an OptimizeRequest and returns an OptimizeResult as JSON, and never edits Lua: read the gear file into a sets file with `.claude/tools/sel-sets.cs`, give the agent the request, write its result back into the gear file by hand, then read the edited file again and run the tests. `docs/frameworks/sel.md` says how Selindrile's framework picks the sets and how to write a result back.
- Run the tools through the launcher, `dotnet run .claude/gear.cs -- <tool> [<option>...]`. A tool runs from its build in `.claude/cache/builds`, which the launcher makes again whenever the tool's source changed.
- After a change, run `dotnet run .claude/gear.cs -- test`. It runs each category of tests (tools, data, gearswap) whose files changed since it last passed, and skips the rest; the data category is the checks of each character's gear files, gear list and docs. Force a category (`test <category>` or `--all`) only when asked. `.claude/tools/README.md` says what each category runs.
