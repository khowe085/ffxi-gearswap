# Notes for Claude

- Read `docs/ffxi-mechanics.md` before building or changing gear sets. It covers the caps, formulas and placement rules sets are built around (casting time, recast, haste, accuracy and attack, magic accuracy, enhancing, enfeebling, magic damage, Cure, blue magic, weapon skills), and the player's standing rules for Vanar's sets.
- Check `docs/gear-notes.md` for any piece you put in a set. It records what the help text and the export don't show: hidden values, set bonuses, conditions and slot or hand restrictions.
- For path-augmented gear (Nyame, Bunzi's, Gleti's and other "Path:" items), take values from `docs/rank-augments.md` at Vanar's rank. `//gs export` shows the path but not the rank.
